### ProtNRD v1.2 - Pairwise/Trimer

This guide details the configuration, database requirements, and execution steps for ProtNRD v1.2, the unified Pairwise/Trimer application with mobile-responsive support.

#### Release notes

- _Unified Application: Pairwise and Trimer run from a single runtime._
- _Mobile Support: Interface adapts to mobile viewports._

---

#### 1. Prerequisites

- Python 3.9+

#### 2. Environment Setup

Create and activate the virtual environment to install required dependencies.

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

#### 3. Database Downloads

Version 1.2 requires both databases placed in a `data/` folder at the project root (create the folder if it does not exist).

- **Pairwise Database:** [Download proteins_v8.db (3.1GB)](https://huggingface.co/datasets/gabriel-newton/proteins/resolve/main/proteins_v8.db?download=true)
- **Trimer Database:** [Download proteins_v9.db (2.0GB)](https://huggingface.co/datasets/gabriel-newton/proteins/resolve/main/proteins_v9.db?download=true)

Place both files so the paths are `data/proteins_v8.db` and `data/proteins_v9.db`.

#### 4. Running the Application

Launch the unified server via the main entry point:

```bash
python run.py
```

The app serves the Pairwise mode at `/v8/` and the Trimer mode at `/v9/` on <http://localhost:8050/>.

#### 5. File Structure Diagram

Ensure the root directory matches this structure:

```text
.
├── data/
│   ├── proteins_v8.db
│   └── proteins_v9.db
├── run.py
├── requirements.txt
├── v8/
├── v9/
└── venv/
```
